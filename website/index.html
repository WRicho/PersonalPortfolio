Overview

This is a static website. Every page is plain HTML styled by one stylesheet, and the home page is filled in by a small script from a list of projects. There is nothing to install or compile.

Design

The look is based on a self-healing cutting mat: emerald green, white measurement markings, and circular guides. The mat pattern sits behind every page. Project pages show their content on a white sheet so the pattern frames the writing without distracting from it.

How it is organised

  • index.html is the home page: featured banner and project list.
  • data/projects.js is the list of projects shown on the home page.
  • projects/ holds one folder per project, each with its own page.
  • css/style.css holds all the styling, and css/mat.svg is the background pattern.
  • website/ is this page.

Adding a project

Copy projects/_template, rename the copy, write the page, then add an entry to data/projects.js with the same id. The README has the full steps.
